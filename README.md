# 直播点歌转盘

观众打赏 → 转盘转动 → 转到哪首主播唱哪首。

## 使用

双击 `index.html` 用 Chrome 打开即可，无需安装。

- **打赏**：模拟观众送礼；每满 N 币转一次，不足部分按观众累计；「自动演示」用于给客户展示。
- **手动转**：点转盘中心，或按空格键。
- **歌单**：增删歌曲、设置权重（权重越高扇区越大）。
- **记录**：本场点歌记录，可标记「唱完」。
- **设置**：打赏规则、唱过移出、音效、绿幕背景、直播模式。

## 推流

设置 → 进入直播模式（地址后加 `#overlay`），在 OBS 中用「窗口采集」抓取浏览器窗口；
开启绿幕背景后加「色度键」滤镜，转盘可叠加在摄像头画面上。按 Esc 退出直播模式。

## 后续：打赏自动触发

当前版本由主播看到打赏后按空格触发（各平台都能用，不违规）。
自动触发需接入平台官方礼物事件，再把事件转成 `sendGift(昵称, 礼物)` 调用：

- B站：直播开放平台（个人开发者可申请）——推荐首选
- 抖音：直播互动玩法开放平台（一般需企业资质）
- YouTube：Live Streaming API 的 Super Chat 事件

不使用非官方抓取工具，避免主播账号被封。
