# 直播点歌转盘（抖音手动模式）

粉丝打赏 → 主播登记 → 转盘排队转 → 转到哪首唱哪首。

在线地址：https://jasonhj.github.io/live-song-wheel/ （也可以直接双击 `index.html` 打开）

## 直播时怎么用

1. 用电脑 Chrome/Edge 打开页面，这个窗口是**控制台**。
2. 设置 → 「进入直播模式」，会弹出一个**只有转盘的窗口**；在抖音直播伴侣里添加「窗口」素材，选这个转盘窗口。
3. 控制台里的操作会实时同步到转盘窗口。

## 登记打赏

- 输入粉丝昵称（可留空，记为「神秘粉丝」），选数量（×1/×10/×66/×188 或自定义），点礼物。
- 快捷键：`1`–`9` 登记对应礼物；在昵称框里用 `Alt/⌥ + 数字`；`空格` 转下一位；`P` 暂停/继续。
- 每满 N 抖币转一次，单次最多转 M 次，不足部分按粉丝累计。

## 排队

- 同一个粉丝连续打赏会合并成一条（×次数）。
- 可以置顶、移出、清空排队；排队数据刷新页面也不会丢。
- 排队方式（设置里切换）：
  - **连续转**：有排队就一个接一个自动转。
  - **唱完再转**：主播按空格才转下一位。

## 设置

礼物名称和抖币价格可编辑（示例价格请按抖音实际价格修改）、歌单与权重、唱过移出、音效、绿幕背景、自动演示。

## 以后：打赏自动触发

需要抖音直播开放平台「互动玩法」（一般要企业资质）。接入后把礼物事件转成 `sendGift(昵称, 礼物, 数量)` 调用即可，转盘和排队部分不用改。
